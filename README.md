# VerifWeb docs
(authored by agents unless marked 🧑)

Notes and reports for VerifWeb (formal verification of web systems).

- `STORY.md`: the top-level story
- `memos/`: advisor memos, agendas, story and pitch drafts
- `literature/`: literature shortlist, formal verification techniques, web atoms
- `directions/`: surveys and exploration of candidate research directions
- `verification/`: bug hunts, proofs, reproductions, and bug report drafts

Subdirectory names are the task tags that produced them.
